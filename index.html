Ten years of drawing the curves

A large part of my years on Simcyp was output and reporting. Scientists judge a simulation by its plots, so I spent a good ten years turning engine results into charts: concentration against time for a virtual population, with the variability band and observed clinical data overlaid.

They were generated from the C++ engine through COM automation into Excel workbooks, so a scientist could open a result and compare it straight away.

  • CurvesConcentration–time profiles, linear for oral doses and logarithmic for intravenous ones.
  • VariabilityThe simulated population as a band around the mean, not a single line.
  • EvidenceObserved clinical data points overlaid, so agreement is visible at a glance.

MoleculeExplore Proof of concept

Claude built this one end to end, with a Unity scene as the render source. A Unity player renders a caffeine molecule on an NVIDIA GPU, encodes it to H.264 with NVENC and streams it over WebRTC to a plain HTML page in Chrome. Pointer, wheel and key input go back over data channels, and the server decides what they do: orbit, grab and rotate, zoom. The idea was mine. Claude did the design, code, builds, testing and docs, driving the Unity editor through the Unity MCP server.

Latency is measured in the frame itself. The server draws the number of the last input it applied as black and white cells, and the page reads them back from the decoded video. On localhost, the median from input to the frame on screen is 70 ms at 1280×720 and 60 fps.
